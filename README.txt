  /vercel.json                 sends X-Robots-Tag: noindex, nofollow, noarchive

This is UNLISTED, not authenticated/private. Anyone who knows the URL can access it.

Suggested Git/Vercel setup:
1. Create a new GitHub repo, e.g. unaffiliated-learning.
2. Put the contents of this folder at the repo root.
3. Import the repo into Vercel as a static project.
4. Add learn.unaffiliated.page as the custom domain in Vercel.
5. Add the DNS record Vercel requests at Porkbun.

No link from the public unaffiliated.page homepage is required.
